# Automatic Pet Feeder
## Features
- Check the weight of food inside the bowl once in a while with load cell
- If the bowl is empty, the servo motor will rotate and bring out the food
- The code is connected with Blynk. There's a option to turn on/off automatic feeding and a button for feeding manually
- There's also dashboard of weight history
## Used hardwares
- ESP32
- Load cell
- MG996R Servo
